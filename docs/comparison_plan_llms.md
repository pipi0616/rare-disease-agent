# 和通用大模型比较的方案（留出集的 200 道）

> 这份方案**在任何一个通用大模型碰留出集之前**写好并提交。考完以后只在最后一节"结果"里填数字，前面的内容不再改。
>
> 写于 2026-10-14。这是正式评测方案第 6 节"留到以后"的第二部分；第一部分（LIRICAL）见 [`comparison_plan.md`](comparison_plan.md)。

## 1. 要回答的问题

我们的 agent 用的是一个便宜的模型（DeepSeek `deepseek-flash`，不思考），加上工具。别人会问：

> **换一个最强的通用大模型，什么工具都不给，直接问，是不是就够了？**

如果最强的模型直接猜就能追上 agent，那工具和 agent 的设计就没有意义。

## 2. 比谁

三家各一个，都是同一价位（每百万 token 输入 $2、输出 $10）的当前主力模型，通过 OpenRouter 调用：

| 公司 | 模型 |
|---|---|
| OpenAI | `openai/gpt-6.1-sol` |
| Anthropic | `anthropic/claude-sonnet-5.5` |
| Google | `google/gemini-4-argon` |

更贵的一档（Claude Opus 5.5 是两倍价，Claude Fable 5.1 是五倍价）这次不比：预算只有 $10。

## 3. 怎么考

- **考法**：和第 09、21 章的"大模型直接猜"完全一样：一道题调用一次，同一份提示词（版本 `direct-v1`），要它列出最可能的 10 个病（带 OMIM 编号）。没有工具，没有检索
- **设置**："深度思考"调到最低档（OpenRouter 的 `reasoning.effort = minimal`），温度 0，要求返回 JSON。回答格式不对，给一次重答的机会（和 DeepSeek 那次一样）

  > 2026-10-14 小考后改，在任何留出集运行之前：原来写的是"关掉深度思考"。小考时三个模型都拒绝关掉（接口返回 400：`Reasoning is mandatory for this endpoint and cannot be disabled`），所以改成三家统一用最低档。在一个简单的问题上，最低档三家都不产生思考 token。
- **题目**：`evals/splits/heldout-papers-200.tsv`：从第 21 章的 840 道里，用固定种子随机抽的 200 道。agent、LIRICAL 和其他系统在这 200 道上的答案都已经记录，不用重跑
- **判分**：同一个判分程序。只认 OMIM 编号：模型把病名说对、编号写错，算错。这对通用模型偏严，第 21 章的"大模型直接猜"也是同样的规则
- **花钱**：先在 ci-20（开发集的 20 道）上每个模型小考一次，量出真实单价，每次上限 $0.5。正式考试每个模型上限 $2.5；**花到上限，程序在下一次调用前自动停下**，那一次考试作废。三家合计不超过 $10

## 4. 事先定好：看什么，怎么算赢

**指标**：第 1 名、前 10 名命中率，带 95% 置信区间；同一批题逐题配对，双侧符号检验，p < 0.05 算显著。

### 主要结论（每个模型一个）

> **在这 200 道题上，最终 agent 的第 1 名命中率，是否高于这个模型直接猜。**

三个模型各比一次。只要有一个模型不显著低于 agent，就如实写出来。

### 次要结论

1. 前 10 名：agent 对每个模型
2. 每个模型对 DeepSeek 直接猜（同一个考法，换了更贵的模型能多多少）
3. 每个模型对 LIRICAL
4. 每个模型的花费和每道题用时
5. 去掉注定答不对的 28 道以后的命中率（探索性）

### 一个说明：这里的"泄露"管不住

这些病例都发表过，大模型训练时可能读过这些论文，答对可能是"记得"而不是"推理"。我们没法替大模型遮挡它脑子里的东西。所以通用大模型的分数是**偏高的上限**，和第 21 章的说明一样。这会让比较对 agent 不利，不会有利。

## 5. 规矩

和前两份方案一样，只有三种情况一次考试作废：记录不完整；有题目因为接口故障没答出来（包括花到上限被停下）；泄露审计不适用（这些模型不读我们的知识库）。

> **2026-10-14 改动，在看到部分结果之后，如实说明。** Gemini 和 Claude 的正式考试各有一部分题因为接口故障没答出来（Gemini 35 道：新账户每分钟限 20 次；Claude 28 道：连接中断），按上面的规矩这两次作废。重考整场要再花约 $3，所以改成：**只把这些因接口故障没答出来的题再问一次**（`raredx eval run --fill-in <那次的编号>`），和那次已经答出的题合在一起算。
>
> 为什么这样不影响结论：这些题没答出来，是因为网络和限流，和题目难不难、模型答没答对无关；再问一次，它们得到的答案和整场重考时会得到的是同一回事；已经答出的题，答案也不会因为重考而变得更好或更差。补问时把调用速度限制在每分钟 18 次以内，连接失败自动重试 5 次。补问之后如果还有题因为接口故障没答出来，再补问，最多三轮；三轮后还有，这个模型的结果作废。

- 不在留出集上改提示词，不换模型，不调设置
- 每一项都报，包括有模型追上 agent 的情况

## 6. 我的预期（写在考之前）

这 200 道题上已经记录的成绩：

| | 第 1 名 | 前 10 名 |
|---|---|---|
| DeepSeek 直接猜 | 15.0% | 25.5% |
| LIRICAL | 28.0% | 47.0% |
| 最终 agent | 43.0% | 60.5% |

我预计：

- **三个模型直接猜，第 1 名都在 20%–35% 之间**，比 DeepSeek 直接猜高不少（模型更大，记得的病更多），但**都显著低于 agent**
- 前 10 名差距更大：直接猜的模型常常把编号写错，前 10 名吃亏更多
- 三家之间差别不会太大（同一价位）
- 每个模型 200 道题花 $1–2
