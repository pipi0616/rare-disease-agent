# 工程笔记 · 边做边学

这个项目一半是作品，一半是学会"公司里的 agent 工程师怎么干活"。
每做一步，这里加一章。每章固定五段：

| 段 | 回答的问题 |
|---|---|
| 做了什么 | 这一步具体改了哪些文件、跑了哪些命令 |
| 工业界叫什么 | 术语中英对照，招聘要求里怎么写 |
| 为什么 | 不做会怎样，旧仓库里对应的教训 |
| ✏️ 你来验证 | 你自己在终端敲几条命令，亲眼看到结果 |
| 思考 | 一个问题，答案在章末 |
