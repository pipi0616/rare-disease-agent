# 工程笔记 · 边做边学

项目每做一步，这里加一章 Jupyter notebook。格式和 qafi-ml-platform 的 notebook 一样。

每章开头三块：**这一章在整个项目里的位置** → **背景**（为什么要做）→ **这一章做的几件事**（一张表）。
然后一步一步来，每一步都是：

| 小节 | 回答什么 |
|---|---|
| 在干什么 | 这一步做的事，一两句话 |
| 背景 | 为什么要做，不做会怎样 |
| 用了什么技术，为什么 | 用的工具，为什么选它 |
| 公司里什么情况怎么做 | 遇到常见情况，公司里怎么处理 |
| 执行 | 要运行的代码 |
| 结果怎么看 | 运行后看什么 |
| 面试怎么说 | 一句英文 |

每章最后：本章小结、面试题、下一章。

## 怎么用

VS Code 打开 `.ipynb`，右上角 **Select Kernel** 选 **raredx (.venv)**，从上往下逐格 `Shift+Enter`。
"准备"那一格不用看代码，直接运行。

仓库里的 notebook 不带运行结果（提交时自动清掉），运行之后才有。

（找不到 raredx 内核的话，在项目目录运行一次：
`uv run python -m ipykernel install --user --name raredx --display-name "raredx (.venv)"`）
