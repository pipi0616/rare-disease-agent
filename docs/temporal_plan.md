# 时间外验证方案（模型训练截止之后才发表的病例）

> 这份方案**在任何系统碰这份题之前**写好并提交。考完以后只在最后一节"结果"里填数字，前面的内容不再改。做法和 [`heldout_plan.md`](heldout_plan.md) 一样：看什么、和谁比、怎么算赢，不能等看了结果再挑。
>
> 写于 2026-10-15。

## 1. 为什么要有这一步

第 21 章的留出集是干净的：按论文分开，只考一次，每道题遮住自己的论文，泄露审计 0 次。但有一样东西遮不住，[`leakage.md`](leakage.md) 第六节第 1 条写过：

> **大模型自己的记忆。** DeepSeek 训练的时候，很可能读过这些论文。……真正的办法：只用模型训练截止之后才发表的病例来考，它不可能读过。

第 21 章按发表年份拆开看过一次，但做不到干净：2024 年以后的只有 107 道，一半注定答不对；年份也只精确到年，而模型训练截止在年中。

这一次只考**模型训练时不可能读到**的论文。

## 2. 考哪些题

**`evals/splits/temporal-2026-10.tsv`：47 篇论文，每篇一道，共 47 道。** 校验码 `7afc314101bf5e491b8b3d88f9019787587d43680b54505f5bfd1c919aba5a41`。

**怎么选的**（代码在 `src/raredx/evals/splits.py` 的 `temporal`，规则由程序检查）：

1. **论文首次公开的日子在 2025-06-01 当天或以后。** 首次公开 = PubMed 收录日、网络首发日、期刊出版日里最早的那个；只有月份的按当月 1 号算，只有年份的按 1 月 1 号算，宁早不晚。942 篇候选论文的日期都从 PubMed 官方接口（E-utilities）查来，存在 `evals/pubmed_dates.tsv`，提交在 git 里
2. **只要没被开发过的论文**，两个来源：
   - 留出集里的 **21 篇**：用第 21 章考过的同一道题
   - Phenopacket Store 在 0.1.27 之后新整理的 **26 篇**：GitHub 主线 2026-10-07 那次提交（`85ffd78`，还没发正式版本），每篇按固定种子抽一道
3. **开发集的论文一篇不要**：开发时用过，而且它们的病人就在"找相似病人"的病例库里

**为什么截止日是 2025-06-01**：我们所有系统里的大模型都是 deepseek-flash，第三方资料普遍写它的训练数据截止在 2025 年 5 月。DeepSeek 自己没有正式公布，这一点照实写在这里。

**这份题的样子：**

- 47 道，44 种病，论文日期从 2025-06-03 到 2026-07-19；47 道都有致病基因
- **14 道注定答不对**：13 道的病只在自己那篇论文里描述过（遮挡以后不存在，规则 3），1 道的病 HPO 没收录。能答的 33 道
- **题很少**：47 道的误差范围约正负 14 个百分点，能答的 33 道约正负 17。只看得出大的差别。Phenopacket Store 每出一个新版本，同样的规则会选出更多题（新版本是新的考卷，名字带日期）

**一件要事先说明的事**：47 道里有 21 道第 21 章考过，各系统答没答对已经记在 `docs/comparison_hits.tsv`、`docs/comparison_llm_hits.tsv`。写这份方案时，我没有去看这 21 道的逐题结果；下面的结论和比较对象都照第 21、23、24、25 章定，不是看了这些题挑的。

## 3. 考的是哪个系统

**`v1.0`，不改。** 考试记录的代码版本会是新的提交（多了读新数据、一个病人列了几个 OMIM 编号时都算对、没有出处论文的病人怎么考），但 agent、工具、提示词的行为和 `v1.0` 完全一样：`git diff v1.0` 在 agent、全部工具和全部对照系统的代码里只有两行，都是类型标注（"找相似病人"的出处字段允许为空，以及没有使用的 `search_disease_texts` 里的一处），对模型看到的内容和算出来的结果没有任何影响。

| 部件 | 配置 |

| 大模型 | DeepSeek `deepseek-flash`，不开思考模式，温度 0 |

| 知识库 | HPO v2026-09-01。它比这些论文晚，可能已经引用了其中一些：47 道里有 29 道，HPO 给这个病做标注时引用了病人自己的论文 |
| 防泄露 | 每道题遮住自己的论文，考完自动审计；规则见 `docs/leakage.md` |

## 5. 事先定好：看什么，怎么算赢

**指标**和第 21 章一样：确诊的病在第 1 名、前 10 名的比例，带 95% 置信区间（Wilson）；两个系统在同一批题上逐题比，双侧符号检验，p < 0.05 算显著。

### 主要结论（只有一个）

> **在模型不可能读过的病例上，最终 agent 的第 1 名命中率，是否高于同一个模型直接猜。**

为什么选这一条：直接猜只能靠模型脑子里的东西。在它没读过的论文上，靠记忆答对的路断了，它只剩从症状推理。agent 用的是同一个模型，但答案来自工具查到的资料。如果 agent 在这里仍然明显胜过直接猜，说明它的本事来自工具，不是来自模型记得论文。

47 道够不够：第 21 章 agent 对直接猜是 257 比 21（840 道里约三分之一的题两者不一样）。照这个比例，这里大约有 15 道两者不一样，测得出来。

- 显著 → 成立
- 不显著 → 如实报告"在模型没读过的病例上，没有证明 agent 胜过直接猜"

### 次要结论（都会报告，不管好坏）

1. 第 1 名、前 10 名：最终 agent 对固定流程（第 21 章的主要结论，在这里再验一次；题少，很可能测不出来）
2. 第 1 名：最终 agent 对 LIRICAL、对先排名再逐条核对、对传统方法
3. 第 1 名、前 10 名：最终 agent 对 GPT-6.1、Claude Sonnet 5.5、Gemini 4 直接猜
4. DeepRare：严格判分和宽松判分（第 25 章的两种判法，同一个大模型裁判），第 1 名和前 5 名，对最终 agent
5. 基因考法，第 1 名：最终 agent 对按基因排名
6. 每个系统的第 1、3、5、10 名命中率和置信区间；去掉注定答不对的 14 道以后的命中率
7. 每个系统的花费和每道题用时

### 分开看的分析（事先说明是探索性的，不用来下主要结论）

- **模型记忆占了多少分**：第 21 章发现越新的论文所有系统都越难，包括不用模型的传统方法。所以单看 agent 掉了多少，分不清是"记忆没了"还是"题变难了"。办法是拿不用模型的"先排名再逐条核对"当参照：比较 agent 领先它多少，在这份题上和在第 21 章 2025 年 6 月以前的论文上，差了多少。领先缩小得多，说明记忆有份
- **大模型直接猜掉了多少**：同一个比法，看直接猜
- **三家通用大模型在它们自己截止以后的论文上**：GPT-6.1 截止以后（2026-05-01 起）的论文有 9 篇，Claude Sonnet 5.5 截止以后（2026-07-01 起）的有 3 篇。题太少，只列出来

## 6. 规矩

和第 21 章一样，**只在下面三种情况下，一次考试作废并重考**，都由程序判断，和分数高低无关：

1. 记录不完整（记下来的题数和应考的不一样）
2. 有题目因为接口故障没答出来（欠费、限流、超时、花到上限）。通用大模型和 DeepRare 照第 24 章的补充办法补问（`--fill-in`），最多三轮
3. 泄露审计没通过

**不许做的事：**

- 不改系统，不调设置，不换提示词；考完不再考第二遍
- 不挑着报：上面列的每一项都报，包括不好看的
- 不因为分数不理想就换指标、换题、换比较对象

## 7. 我的预期（写在考之前）

第 21 章留出集上：最终 agent 42.4% / 62.0%，直接猜 14.3% / 29.0%；2024 年以后发表、能答的题上，agent 第 1 名 32.7%，直接猜 7.3%。

这份题上我预计：

- **直接猜第 1 名几乎答不对**：0–3 道（0%–6%）
- **最终 agent 第 1 名在 20%–35%**（10–16 道），主要结论成立
- **agent 对固定流程测不出显著差别**：题太少
- **LIRICAL 第 1 名在 15%–25%**；GPT-6.1 直接猜比 deepseek 直接猜高，因为它可能读过这些论文
- **"模型记忆占多少分"那一项**：agent 领先"先排名再逐条核对"的幅度，和以前差不多（变化在 5 个百分点以内）。也就是说，我认为 agent 的分数主要不是靠记忆。这一项题少，可能看不清

## 8. 结果

> 2026-10-19 考完后填写（v1.0 考于 2026-10-15）。第 1–7 节是考前写的，没有改动（git 记录可查）。第 9 节是考完以后加的。记录在 MLflow 的 `eval/temporal-2026-10` 和 `eval/temporal-2026-10+genes`；逐题结果在 `docs/temporal_hits.tsv`。

**考试本身**：没有作废的；泄露审计全部通过（不调工具的系统没有可审的）。接口故障补问了两家：GPT-6.1 14 道、Claude Sonnet 5.5 11 道，各补问一轮补齐。

### 主要结论：不成立

| | 最终 agent | 大模型直接猜 | 只有 agent 对 : 只有直接猜对 |
|---|---|---|---|
| 第 1 名（47 道） | 23.4% [13.6–37.2] | 8.5% [3.4–19.9] | 9 : 2，p = 0.065 |

方向对，但没到事先定的 p < 0.05。**在模型没读过的病例上，没有证明 v1.0 胜过直接猜。**

## 9. 考完以后

v1.0 在 RareBench 上输给了直接猜，之后改成了 `hypothesis-agent`（提示词 `hypotheses-v2`，代码 `788e56e`；改了什么、为什么改，见 [`external_plan.md`](external_plan.md) 第 9 节）。新版在这 47 道上考了一次（2026-10-18），系统配置和第 3 节一样，只是 agent 换了。

**这份题对新版是干净的**：v1.0 在这里的总分我改版时知道，但这份题的逐题错误我没有读，也没有拿它调过新版；新版在它上面只考了这一次。要说明的一点：同一份题现在考过两个版本，第二次过线，比只考一次的过线分量轻一些。

**新版对直接猜，第 1 名 10 : 2，p = 0.039；前 10 名 8 : 0，p = 0.008。第 5 节的主要结论，换成新版来回答，是"成立"。**
